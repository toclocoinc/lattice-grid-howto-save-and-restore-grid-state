How to save and restore a grid's state

Sort the task list below by owner or priority, drag a column edge to resize it, then click "Save". The arrangement goes to localStorage and into this page's own URL, so reloading the page, or opening the saved link again, brings the same sort and widths straight back. Read the full how-to on latticegrid.dev.
